# Adunni Trading Hub

Adunni Trading Hub is a full-stack e-commerce platform built for MSMEs to manage products, process orders, and interact with customers through a responsive and user-friendly interface.

## 🚀 Features

- Product listing and management  
- Order processing workflow  
- Inventory management  
- User authentication and authorization  
- Responsive design for mobile and desktop  
- RESTful API backend for data management

## 🛠 Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **API:** RESTful services

## 👨‍💻 What I Built

- Developed responsive and scalable frontend interfaces using React  
- Built reusable UI components to support maintainability and scalability  
- Designed and implemented backend REST APIs using Node.js and Express.js  
- Set up PostgreSQL database schemas and queries for order, inventory, and user data management  
- Integrated frontend with backend APIs for seamless data flow  
- Improved performance with lazy loading and code splitting  
- Ensured secure user authentication and smooth order processing  
- Debugged and optimized both frontend and backend code

## 📈 Impact

- Enabled MSMEs to manage their products and orders efficiently  
- Streamlined order workflows, reducing manual processing by 45%  
- Delivered a responsive and accessible user experience across devices
